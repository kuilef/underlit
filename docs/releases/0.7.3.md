## Underlit 0.7.3 - kuilef fork

Based on DietervanDortmont/underlit main at `1483629` (v0.7.2).

### Install

Download **UnderlitSetup-0.7.3.exe**, quit any running Underlit, and run the
installer. It includes .NET Desktop Runtime, creates a Start menu shortcut and a
Windows uninstall entry, and offers optional desktop and startup shortcuts.
Settings in `%APPDATA%\Underlit` are retained when upgrading or uninstalling.

For an existing .NET 8 Desktop Runtime x64 installation, the
`desktop-runtime-win-x64.zip` contains a smaller portable EXE. The `portable`
archive includes .NET and needs no separate runtime installation.

### Changes

- Secondary monitors without usable hardware brightness now follow the positive
  brightness range through a dim overlay.
- Failed hardware and gamma brightness writes receive per-monitor software
  compensation. Reconnects and native WMI changes reapply the correct state.
- Repeated gamma writes are cached briefly to reduce software dimming latency.
- Smaller packages use compression and omit the extra ReadyToRun image.
- Uninstall removes the application's startup registry entry, scheduled autostart
  task and legacy Startup shortcut while preserving user settings.

The Windows pipeline runs 23 engine/display regression checks, then verifies
installation, shortcuts, startup registration/task cleanup, settings preservation and removal
on a disposable runner before publishing. `SHA256SUMS.txt` covers the downloads.
The builds are not code-signed.

Software fade duration still controls the intended smooth transition. Set it to
0 for an immediate change. Existing HDR and exclusive-fullscreen limitations
remain; gamma failure compensation does not restore warmth on an HDR display.
